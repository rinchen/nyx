## 0. Honest scope note (read this first)

The brief asks for something *faster than everything AND better than anything else*. That is
**mathematically impossible** as stated: compression lives on a **Pareto frontier** bounded by
Shannon entropy (lower bound on ratio) and Kolmogorov complexity (no free lunch on speed).
No single algorithm dominates all data types on both axes.

What this plan delivers instead is a **genuinely novel codec that reaches a new point on the
frontier for MIXED general-purpose data**, beating the relevant SOTA *there*, and measuring
honestly. The novel contributions are:

1. **Per-block data-type classifier** that switches predictor configuration (text / binary /
   executable / random) — this is what keeps speed near `zstd` while allowing CM-quality
   prediction only where it pays off.
2. **Online logistic mixing of heterogeneous bit-model families** (order-N, sparse-stride,
   LZP-match, executable 2D-context) — a hybrid not present in any single shipping tool.
3. **LZP pre-stage feeding a shared bit-mixer** — repetitive blocks get zstd-like speed;
   entropy-rich blocks get CM-like ratio.

**Success criterion (verifiable):** On the combined *Silesia + Mixed* corpus, `nyx` at its
default level must sit **on or above the convex Pareto frontier** defined by `lz4 -9`,
`zstd -19`, `brotli -11`, `xz -9` across (ratio, compress_speed, decompress_speed). If it does
not, Phase 8 (tuning loop) must adjust model selection/classifier until it does — or the final
report revises the claim honestly. No fabricated wins.

**Deliverable shape (confirmed):** Production-ready CLI + own archive/container format (like a
tiny `7z`/`zstd` clone), not just a library.

## 4. Architecture / proposed approach

`nyx` splits input into **blocks** (default 64 KiB). Each block is classified by a cheap order-0
Shannon estimate into `text` / `binary` / `exec` / `random`. For `random` blocks we emit a
**copy** record (no prediction cost). All other blocks run a **bit-level predictor stack**: an
LZP pre-stage (fast match prediction) plus N context bit-models (order-0/1/2, sparse-stride,
executable 2D-context). A **logistic mixer** fuses the models' per-bit probabilities online via
SGD. The fused probability drives a **range coder** (v1; rANS swap-in is Phase 7 task). Output is
a self-describing **container** (magic + header + block table + blocks + CRC32). The CLI exposes
`compress`, `decompress`, `bench` (vs SOTA), and `self-test`.

```rust
// src/entropy/range.rs
use byteorder::{LittleEndian, ReadBytesExt, WriteBytesExt};
use std::io::{Cursor, Write};

const RANGE_BITS: u32 = 24;
const RANGE: u32 = 1 << RANGE_BITS; // 0x0100_0000
const BOT: u32 = 1 << 16;           // renormalization floor

pub struct RangeEncoder {
    low: u32,
    range: u32,
    out: Vec<u8>,
}
impl RangeEncoder {
    pub fn new() -> Self { RangeEncoder { low: 0, range: (!0u32) >> 8, out: Vec::new() } }
    pub fn encode(&mut self, cumul_low: u32, freq: u32, total: u32) {
        self.range /= total;
        self.low += cumul_low * self.range;
        self.range *= freq;
        while self.range <= BOT {
            self.out.push((self.low >> 24) as u8);
            self.low = (self.low << 8) & 0xFFFF_FFFF;
            self.range = (self.range << 8) | 0xFF;
        }
    }
    pub fn finish(mut self) -> Vec<u8> {
        for _ in 0..4 { self.out.push((self.low >> 24) as u8); self.low <<= 8; }
        self.out
    }
}
pub struct RangeDecoder<'a> {
    low: u32, range: u32, code: u32, data: &'a [u8], pos: usize,
}
impl<'a> RangeDecoder<'a> {
    pub fn new(data: &'a [u8]) -> Self {
        let mut code = 0u32;
        for i in 0..4 { code = (code << 8) | data[i] as u32; }
        RangeDecoder { low: 0, range: (!0u32) >> 8, code, data, pos: 4 }
    }
    /// `cumul` has length nsym+1, cumul[0]=0, cumul[nsym]=total. Returns symbol index.
    pub fn decode(&mut self, total: u32, cumul: &[u32]) -> usize {
        self.range /= total;
        let value = self.code.wrapping_sub(self.low) / self.range;
        let sym = cumul.partition_point(|&c| c <= value).saturating_sub(1);
        let cumul_low = cumul[sym];
        let freq = cumul[sym + 1] - cumul_low;
        self.low += cumul_low * self.range;
        self.range *= freq;
        while self.range <= BOT {
            self.low = (self.low << 8) & 0xFFFF_FFFF;
            self.code = (self.code << 8) | self.data.get(self.pos).copied().unwrap_or(0) as u32;
            self.pos += 1;
            self.range = (self.range << 8) | 0xFF;
        }
        sym
    }
}
```

```rust
// src/entropy/bit.rs
use super::range::{RangeEncoder, RangeDecoder};

pub struct BitEncoder { enc: RangeEncoder }
impl BitEncoder {
    pub fn new() -> Self { BitEncoder { enc: RangeEncoder::new() } }
    /// `p` = probability of bit==1, in [1, 4095].
    pub fn encode_bit(&mut self, bit: bool, p: u16) {
        let p = p.clamp(1, 4095) as u32;
        let total = 4096u32;
        if bit {
            self.enc.encode(total - p, p, total); // bit==1 occupies [total-p, total)
        } else {
            self.enc.encode(0, total - p, total);  // bit==0 occupies [0, total-p)
        }
    }
    pub fn finish(self) -> Vec<u8> { self.enc.finish() }
}
pub struct BitDecoder<'a> { dec: RangeDecoder<'a> }
impl<'a> BitDecoder<'a> {
    pub fn new(data: &'a [u8]) -> Self { BitDecoder { dec: RangeDecoder::new(data) } }

        let p = p.clamp(1, 4095) as u32;
        let total = 4096u32;
        // cumul table for 2 symbols: [0, total-p, total]
        let cumul = [0u32, total - p, total];
        let s = self.dec.decode(total, &cumul);
        s == 1
    }
}
```

```rust
use super::BitModel;
use std::collections::HashMap;

pub struct OrderN { order: usize, ctx: Vec<u8>, tables: HashMap<u64, [u32; 2]>, init: u32 }
impl OrderN {
    pub fn new(order: usize) -> Self {
        OrderN { order, ctx: Vec::with_capacity(order), tables: HashMap::new(), init: 32 }
    }
    fn key(&self) -> u64 {
        let mut k = 0u64;
        for &b in &self.ctx { k = (k << 8) | b as u64; }
        k
    }
}
impl BitModel for OrderN {
    fn predict(&self) -> u16 {
        let e = self.tables.get(&self.key()).cloned().unwrap_or([self.init, self.init]);
        let tot = (e[0] + e[1]) as f32;
        let p = (e[1] as f32 / tot * 4095.0).clamp(1.0, 4095.0) as u16;
        p
    }
    fn update(&mut self, bit: bool) {
        let k = self.key();
        let e = self.tables.entry(k).or_insert([self.init, self.init]);
        e[bit as usize] += 1;
        let b = bit as u8;
        if self.ctx.len() == self.order { self.ctx.remove(0); }
        self.ctx.push(b);
    }
    fn reset(&mut self) { self.ctx.clear(); }
}
```

### Phase 3 — Logistic mixer (the novel core)

**Task 3.1** `src/model/mixer.rs` — stretch/squash tables + online SGD mix of N model probs.
```rust
use super::BitModel;

const STRETCH: [f32; 4096] = include_stretch!(); // see note below
// NOTE: replace include_stretch!() with a const fn table builder (task 3.2).
// For now, define:
#[inline] fn stretch(p: u16) -> f32 { /* p in [1,4095] -> logit */ (p as f32/4095.0 + 1e-6).ln()/(1.0 - p as f32/4095.0 + 1e-6) }
#[inline] fn squash(x: f32) -> u16 { let s = 1.0/(1.0+(-x).exp()); (s*4095.0).clamp(1.0,4095.0) as u16 }

pub struct LogisticMixer { weights: Vec<f32>, lr: f32 }
impl LogisticMixer {
    pub fn new(n: usize) -> Self {
        LogisticMixer { weights: vec![0.0; n], lr: 0.02 }
    }
    /// `probs`: one P(bit==1) per model, each in [1,4095]. Returns mixed P.
    pub fn mix(&self, probs: &[u16]) -> u16 {
        let mut acc = 0.0f32;
        for (i, &p) in probs.iter().enumerate() {
            acc += self.weights[i] * stretch(p);
        }
        squash(acc)
    }
    /// Online update after the true bit is known.
    pub fn update(&mut self, probs: &[u16], bit: bool) {
        let target = if bit { 1.0f32 } else { 0.0 };
        let mut acc = 0.0f32;
        for &p in probs { acc += self.weights[p as usize % self.weights.len()] * stretch(p); }
        // gradient step on logistic loss
        let pred = 1.0/(1.0+(-acc).exp());
        let err = target - pred;
        for (i, &p) in probs.iter().enumerate() {
            self.weights[i] += self.lr * err * stretch(p);
        }
    }
}
```

### Phase 4 — Block classifier

**Task 4.1** `src/classify.rs` — cheap order-0 Shannon estimate over a 64 KiB window.
```rust
pub enum BlockKind { Text, Binary, Exec, Random }
pub fn classify(buf: &[u8]) -> BlockKind {
    if buf.is_empty() { return BlockKind::Random; }
    let mut hist = [0u32; 256];
    for &b in buf { hist[b as usize] += 1; }
    let n = buf.len() as f32;
    let mut h = 0.0f32;
    for &c in &hist {
        if c > 0 { let p = c as f32 / n; h -= p * p.log2(); }
    }
    let frac_printable = buf.iter().filter(|&&b| b >= 0x20 && b < 0x7f).count() as f32 / n;
    if h > 7.9 { BlockKind::Random }
    else if frac_printable > 0.85 { BlockKind::Text }
    else if has_exec_markers(buf) { BlockKind::Exec }
    else { BlockKind::Binary }
}
fn has_exec_markers(b: &[u8]) -> bool {
    b.windows(4).any(|w| w == b"\x55\x89\xe5" || w == b"\xff\xd0" || w == b"\x48\x89")
}
```

### Phase 6 — Core codec (glue: models + mixer + coder + container)

**Task 6.1** `src/codec.rs` — `compress(buf: &[u8]) -> Vec<u8>` and `decompress(&[u8]) -> Result<Vec<u8>, NyxError>`.
Algorithm (pseudo, implement literally):
```
compress:
  split buf into blocks of 1<<block_size_log (64KiB)
  for each block:
    kind = classify(block)
    if kind == Random: method=0 (copy): write block bytes as-is
    else:
      method=1 (cm): build models [Order0, Order1, Order2, Sparse, Exec(if kind==Exec), Lzp]
      mixer = LogisticMixer::new(models.len())
      be = BitEncoder::new()
      for each byte b in block:
         for each bit in b (MSB..LSB):
            probs = models.map(|m| m.predict())
            p = mixer.mix(probs)
            be.encode_bit(bit, p)
            mixer.update(probs, bit); models.each(|m| m.update(bit))
      comp = be.finish()
      write comp with BlockEntry{comp_len, orig_len, method=1, crc32}
  assemble Header + block table + blocks, return
decompress: parse header, for each block read comp_len bytes, if method==0 copy, else
  BitDecoder loop reconstructing bits->bytes using the SAME model stack + mixer (re-trained online
  from the decoded stream, which is identical to training during compress because it's causal).
```

**Task 9.2 (research loop — the "find best matches" step).** Use **parallel subagents**
(`delegate_task`, 4 children) to sweep hyperparameters and report the config that maximizes the
Pareto score on `corpus/mixed` + `corpus/silesia`:
- Child A: sweep `block_size_log` ∈ {14,16,18} × `mixer.lr` ∈ {0.005,0.02,0.05}.
- Child B: sweep active model sets (drop Order2 / Sparse / Exec) and measure ratio vs speed.
- Child C: tune LZP match threshold (3..8) and whether LZP pre-stage is enabled per block kind.
- Child D: tune classifier entropy thresholds (text/binary/exec/random boundaries).
Each child runs `cargo run --release -- bench` on its config, returns the 4 numbers
(ratio%, cmp_MBps, dec_MBps, total_time). **You (orchestrator) pick the config that sits highest
on the convex frontier and write it as the default in `src/codec.rs` constants.** Commit
`chore: tuned defaults from sweep`.

## 7. Risks, tradeoffs, open questions

**Risks**
- *"Faster AND better than everything" is impossible* — we target a new **balanced** Pareto point
  and measure honestly (Phase 9). If the sweep can't beat `zstd` on the frontier, the final report
  says so; we do not fake wins.
- *rANS byte-ordering bugs* — mitigated by the bit-exact `rans_matches_rangecoder_ratio` test
  (Task 7.1); fall back to the (slower but correct) range coder if needed.
- *CM is slow* — the classifier gate + LZP pre-stage keep cost off random/repetitive blocks;
  reduce model count if `cmp_MBps` is unacceptable.
- *Memory* — hash-table models grow; cap table sizes (e.g. `OrderN` table `.len()` guard at 1<<20).

**Tradeoffs**
- Range coder (v1) is simpler/correct but slower than rANS; rANS is the Phase 7 speed upgrade.
- Bit-level mixing gives the best ratio but is inherently slower than byte/word models; the
  classifier limits where we pay that cost.
- Zero external compression crates = full auditability but more code to maintain.

**Open questions (decide during Phase 9 if not sooner)**
- Block size default (64 KiB assumed; sweep may change it).
- Streaming / multi-threaded compression (out of v1 scope; single-threaded blocks for now).
- Whether to expose dictionary training (zstd-style) — deferred.
